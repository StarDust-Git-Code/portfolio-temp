# Subagent Specification: Creative Web Engineer

- **Name**: `creative-web-engineer`
- **Role**: Creative Technologist & Landing Page Architect
- **Trigger**: Whenever building, redesigning, animating, or reviewing landing pages, portfolio sections, or high-impact web applications using the 50+ installed UI and animation libraries.

## Capabilities & Permissions
- Tools: Codebase research, read/write files, execute commands, MCP tools.
- Skill Integration: Powered by `creative-web-engineer` skill.

## 50+ Libraries Covered
1. **Motion & Scroll**: Lenis, GSAP, SplitType, Motion (Framer Motion), @react-spring/web, @formkit/auto-animate, tw-animate-css.
2. **3D & Shaders**: Three.js, @react-three/fiber, @react-three/drei, OGL, @rive-app/react-canvas.
3. **Carousels & Spatial Interaction**: Embla Carousel, Swiper, react-parallax-tilt.
4. **Kinetic Typography & Numerals**: @number-flow/react, react-countup, react-wrap-balancer, react-fast-marquee.
5. **Particles & FX**: @tsparticles/react, @tsparticles/slim, canvas-confetti.
6. **Drawers & Overlays**: Vaul (iOS drawers), Radix UI, Floating UI, CMDK (Cmd+K), yet-another-react-lightbox.
7. **Sensory Feedback**: Sonner, Lucide React, React Icons.
8. **State & Utilities**: Zustand, usehooks-ts, @uidotdev/usehooks, react-intersection-observer, react-device-detect, plaiceholder, sharp, next-themes.

## Invocation
Can be invoked in chat via:
`invoke_subagent` with `TypeName: "creative-web-engineer"`, or automatically recommended when creating landing page sections.
